func varMeans(inputData []stats.Coordinate) (xMean float64, yMean float64) {

func gradient(inputData []stats.Coordinate) (gradient float64) {
    // Calculate gradient using Sxy / Sxx
    xMean, yMean := varMeans(inputData)

Optimized Approach
Instead of calculating the gradient and y-intercept separately, you can compute both coefficients in a single pass through the data. This avoids redundant computations and improves efficiency.

Improved Code
func linearRegression(inputData []stats.Coordinate) (gradient, intercept float64) {
    var sumX, sumY, sumXY, sumX2 float64
    n := float64(len(inputData))

    // Single loop to calculate all required sums
    for _, point := range inputData {
        sumX += point.X
        sumY += point.Y
        sumXY += point.X * point.Y
        sumX2 += point.X * point.X
    }

    // Calculate gradient (slope) and intercept
    gradient = (n*sumXY - sumX*sumY) / (n*sumX2 - sumX*sumX)
    intercept = (sumY - gradient*sumX) / n

    return gradient, intercept
}

Explanation of the Changes
Single Pass Calculation:

The function computes all necessary sums (sumX, sumY, sumXY, sumX2) in a single loop, reducing the number of iterations over the dataset.
This improves performance, especially for large datasets.
Mathematical Formulas:

Gradient (slope):
[ m = \frac{n \cdot \text{sumXY} - \text{sumX} \cdot \text{sumY}}{n \cdot \text{sumX2} - \text{sumX}^2} ]
Intercept:
[ b = \frac{\text{sumY} - m \cdot \text{sumX}}{n} ]
Efficiency:

By combining the calculations for gradient and intercept, the function avoids redundant calls to varMeans and gradient.
